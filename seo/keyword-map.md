# Keyword map

The single owner of every keyword on the site. **Each primary keyword belongs to exactly one URL.** Before creating or retitling a page, search this file for the keyword and its close variants. If another URL owns it, update that URL instead, or choose a clearly different intent. See [cannibalization-report.md](cannibalization-report.md).

## How to read this

- **Primary keyword (owner):** the query this URL is built to rank for. No other URL may target it or a close variant in its title, H1 or description.
- **Secondary keywords:** supporting variants the page can naturally cover. Another page may mention them in body copy, but not in its title or H1.
- **Semantic terms / entities:** topics and named things the page should cover to be complete, for example Dubai Municipality, service lifts and NOCs. Write them where they help the reader. Never list them.
- **Intent:** what the searcher wants. Commercial pages sell a service. Informational pages answer a question and link to the matching service.

**Keywords here are targets chosen from each page's content and purpose. They are not measured.** There is no search volume, difficulty or ranking data for this site yet. When Google Search Console has data, add a `Volume / clicks` note per URL from real queries, and revisit any keyword the site doesn't get impressions for. Do not add estimated or invented volumes.

## Rules

1. **One primary keyword per URL. One URL per primary keyword.** This file was generated with a check that fails on any duplicate.
2. **Service pages own "<service> dubai".** Guides on the same subject must target a question or problem ("how to…", "what to do with…"), never the service keyword.
3. **Area pages own "junk removal <area>".** Don't create service-plus-area pages, such as "sofa removal JVC". They would compete with both the service page and the area page. Local service variants live on the area page as secondary keywords.
4. **Each cluster has one pillar** (the service page, or `/` for the head term). Supporting articles link up to their pillar. The pillar links back to the articles where it helps the reader.
5. **The brand name is an exact-match phrase** ("Dubai Junk Removal Services"), so the homepage owns both the brand and "junk removal dubai". `/services` is a catalogue page and must not be retitled to compete for the head term.
6. **Planned guides reserve their keyword now.** The 60 guides in the 30-day plan are listed below with their keywords reserved, so no other page may take them. The reservation becomes ownership when the guide goes live.
